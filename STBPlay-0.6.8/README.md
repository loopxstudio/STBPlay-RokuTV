# STBPlay 0.6.8

Android TV / Google TV media player. Open this folder in Android Studio.

Start with [release preparation](publishing/docs/READ-ME-FIRST.md). Final test APK and publishing material are prepared for review; public privacy hosting, upload-key backup, Console setup and the known HTTP secure-transmission policy risk remain publisher actions.

The app supplies no channels, subscriptions or media. Use sources you are authorized to access.

Preview the complete public policy locally: [Privacy policy webpage](publishing/privacy-site/index.html). Upload only the contents of `publishing/privacy-site/` to your GitHub Pages repository. Settings lists the bundled third-party licenses under **App Licenses**.
