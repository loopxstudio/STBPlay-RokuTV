# Store listing assets

Use the PNG originals under `assets/`. `asset-manifest.json` records exact sizes after validation.

| Asset | File / folder | Purpose |
| --- | --- | --- |
| App icon | app-icon-512.png | 512×512 PNG export of the existing app artwork |
| Feature graphic | feature-graphics/ | Three 1024×500 RGB PNG alternatives; recommended option 02. Upload one primary option, not all three in a single image. |
| Android TV store banner | tv-banner-1280x720.png | Console's TV banner, 1280×720 RGB PNG |
| TV launcher banner | tv-launcher-banner-320x180.png | Installed TV launcher artwork, already integrated into the app |
| Android TV screenshots | screenshots/ | Eight 1920×1080 RGB PNGs; unaltered visual content captured from the current app UI |

Screenshots use fictional demo profiles/catalogs and developer-generated synthetic video. They contain no provider credentials or copyrighted program images. The production app does not bundle those catalogs or test footage. The captures demonstrate the interface when a user supplies a compatible source; do not describe the demo titles as included channels/content.

The screenshot sequence is Home, Live TV, Movies, Series, Sources, Settings, About/privacy, Player. Do not upload a QA contact sheet as a screenshot. Do not add promotional overlays, hardware frames or broadcaster logos.

The three feature graphics are original code-drawn layouts. Platform names describe compatibility; no Google/Android logo or certification badge is used. Fonts are rendered using locally installed fonts; font binaries are not redistributed. The asset generator is provided as an optional editing aid and is not required to build the Android app.

Source: [Google Play preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151).
